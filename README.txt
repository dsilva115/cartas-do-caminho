AS CARTAS DO CAMINHO — KANDERSTEG 2026

Conteúdo
- index.html: aplicação
- manifest.webmanifest: permite instalar como PWA
- sw.js: mantém a aplicação disponível offline depois da primeira abertura

Uso rápido
1. Durante o hike, use um baralho normal sem os Ases.
2. A pessoa tira uma carta física.
3. Na aplicação escolha o naipe e o valor.
4. Leia a carta e siga o símbolo de participação.
5. Pode marcar a carta como feita para evitar repetições.
6. Os Ases ficam fora da aplicação e são usados na reflexão da noite.

Progressão sugerida
- Início: 2–5
- A subir: 2–8
- Mais alto: 2–Rei

Para funcionar como app instalada e offline no iPhone/Android:
- Coloque esta pasta num alojamento estático HTTPS (GitHub Pages, Netlify, Cloudflare Pages, etc.).
- Abra o endereço uma vez com internet.
- No iPhone: Partilhar > Adicionar ao ecrã principal.
- Depois disso, a aplicação continua a abrir sem ligação.

O ficheiro index.html também não usa bibliotecas, fontes, imagens ou dados externos.
